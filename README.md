Student Grade Calculator

Description

A Python program that calculates a student's total marks, percentage, grade, and pass/fail result.

Objective

To practice Python conditions, loops, arithmetic operations, and input validation.

Tools Used

- Python
- Visual Studio Code

Features

- Accepts marks for five subjects.
- Validates marks between 0 and 100.
- Calculates total marks and percentage.
- Assigns grades based on predefined criteria.
- Displays pass or fail status.

Grade Criteria

- 90–100%: A+
- 80–89.99%: A
- 70–79.99%: B
- 60–69.99%: C
- 50–59.99%: D
- 35–49.99%: E
- Below 35%: F

How to Run

Run "python3 grade_calculator.py" in the terminal.

Output

Displays the student's name, total marks, percentage, grade, and result.
